# CS50's Introduction to Artificial Intelligence with Python

Selected implementations from **CS50's Introduction to Artificial Intelligence with Python**, Harvard University's introductory course covering fundamental concepts and algorithms in Artificial Intelligence.

This repository contains hands-on implementations covering **constraint satisfaction, reinforcement learning, machine learning, neural networks, and natural language processing**.

## 🤖 Projects

| Project       | Area                        | Implementation                                                                       |
| ------------- | --------------------------- | ------------------------------------------------------------------------------------ |
| **Nim**       | Reinforcement Learning      | Q-learning agent that learns to play Nim through self-play                           |
| **Shopping**  | Machine Learning            | k-Nearest Neighbors classifier for predicting online shopping purchase intent        |
| **Crossword** | Constraint Satisfaction     | Crossword generator using node consistency, arc consistency, and backtracking search |
| **Parser**    | Natural Language Processing | Context-free grammar parser for extracting noun phrase chunks                        |
| **Traffic**   | Neural Networks             | Convolutional Neural Network for German traffic sign classification                  |

## 🧠 Concepts
